# Guía de estudio V2

Empezá con topic y study: el diagnóstico establece la línea base. Durante explain y practice respondé retrieval y autoexplicación; después de observar tu trabajo, record-session, update-socratic-response, record-evidence o record-assessment aplican revisión e idempotencia. Un score bajo pide feedback y correction; review agenda spacing e interleaving. Transfer lleva la idea a otro contexto. Recién tras 48+ horas, una evaluación demorada aporta evidencia útil. Mastery se deriva de evidencia diversa y scheduler; jamás se marca manualmente. El dashboard LAN no tiene auth.
